# wave-qt（QML 版）の今の状態

GTK 版（wave-gtk）と同じ並び・同じ機能を目指している。2026-11-09 の時点。

## できているもの

- 起動・読み込み中・ログインの入り口（「ログイン」は `wave-gtk --login` を別に開く。「ブラウザのログインを使う」はプロファイルを選んで読む）
- 上の帯: 戻る・進む（押せるときだけ）、ホーム、検索の欄と打ち込み中の候補、アカウント（写真・設定・再生履歴・ログアウト）
- マイライブラリ: 種類のチップ、中の検索、並べ方（最近・最近追加した順・アルファベット順）、リストとグリッド、高く評価した曲・ダウンロードの行、右クリックの「再生」
- ホーム: チップ、最近聴いたもの、登録したアーティストの新作、新作、棚、下の端で続き、読めなかったときの「もう一度読み込む」。気分・ジャンルのページ
- 検索: 最近の検索（消す・すべて消去）、すべてをブラウズ（気分のタイル）、タブ（すべて・曲・アルバム・アーティスト・ライブ・ポッドキャスト・エピソード）と続き
- アルバム・プレイリスト（続き）・再生履歴・アーティスト（人気の曲・アルバムの棚・動画・登録）
- 歌詞（時刻付きは歌っている行を明るくして寄せ、押すとその位置へ。背景はぼかしたジャケット）
- 右の欄の再生中（次の曲・キューを開く・評価）とキュー（履歴・キューを消去・次に流れる曲の消去・キューから削除）
- 下の帯（曲・評価・シャッフル・前・再生・次・リピート・位置・LIVE・歌詞・キュー・端末名・再生中の画面・全画面・音量）、全画面の再生中（F11・Esc）、近道（Space・Ctrl+←/→・Alt+←/→・Ctrl+F）
- 曲のメニュー（次に再生・キューに追加・ラジオ・高く評価・プレイリストに追加・アルバム・アーティスト）
- 設定（アカウント・再生・ダウンロードの入り切りと通信・Discord・言語・このアプリについて）
- Omarchy のテーマの色と Hyprland の角の丸み（切り替えるとその場で変わる）、MPRIS、Discord、新作の確かめ

## 足したもの（2026-11-09 の続き）

- Claude の欄（会話・頼みの例・止める・新しい会話・これまでの会話・[mm:ss] のリンク）と、設定の「Claude」（つなぐ・切る）
- 端末の連携のページ（知らせの帯・ほかの端末の再生・はじめる・QR と6桁・端末の一覧・外す・ログインを渡す・中継の場所）と、下の帯の端末の小窓
- ダウンロードのページ・曲のメニューの「ダウンロード」・アルバムとプレイリストの頭のダウンロード
- ポッドキャストの番組のページ（YouTube・RSS・保存と登録・続き）・新しいエピソード・RSS の番組を探すページ
- 映像（MV。appsink → C++ の VideoFrame）。再生中の欄と全画面の再生中の「曲｜動画」
- プレイリストの作成・自分のプレイリストから外す
- 新作の通知（freedesktop の通知。押すとアルバムかアーティストを開く）

## 足したもの（その3）

- 映像だけを窓いっぱいに出す層（右の欄の映像の「映像を大きく見る」・全画面の再生中の「映像だけを窓いっぱいに」。小窓・窓の全画面・やめる（Esc）。ダブルクリックで窓の全画面）
- 映像の小窓（PiP。別の窓。指を乗せると前・再生・次と「wave に戻して大きく見る」、ダブルクリックでも戻る）
- 右の欄の流れる歌詞の箱（押すと歌詞のページ）と、全画面の再生中の流れる歌詞（行を押すとその位置へ）
- 検索の「歌詞」のタブ（合った行を曲名の下に）
- アルバム・プレイリストの一覧の中の検索（虫眼鏡で開く）・並べ替え（カスタム順・追加した日・リリース日・タイトル・アーティスト・アルバム・再生時間。プレイリストごとに覚える）・曲の種類のチップ（その下の横に送れる帯）。プレイリストは届いたページから順に足す
- 窓の幅の段（GTK 版と同じ5段。右の欄は 1180px 以上、Claude の欄は 880px 以上、端末名は 1400px 以上、音量のバーは 1180px 以上）

## まだ無いもの（GTK 版にはある）

- 小窓を常に手前に出すこと（Hyprland は Qt の WindowStaysOnTopHint を見ない。GTK 版も同じ）

## 確かめていないこと

- 本物の Hyprland の窓で開くこと（offscreen でしか開いていない）。窓の app id・アイコン・メディアキー・小窓の窓の出方・窓の全画面
- ログインした状態（ライブラリ・評価・アカウントの写真・ログアウト・プレイリストのページ。プレイリストはログインしていないと読めない）。人の機械のキーリングに触れないよう、ログインせずに撮った
- 「ログイン」から wave-gtk --login を開いて戻ってくる流れ
- 端末の連携の、中継につないだ状態（cramgent では中継の場所を入れていない。加入の手順は確かめ用の WAVE_DEMO_DEVICES で出した）
- Claude の答え（中継が無い。つないでいないときの答えまで）
- 新作の通知が実際に出ること（撮るときは自分だけの D-Bus で、通知の口が無い）
- ダウンロードで実際に曲を取ること、ポッドキャストの保存・登録（ログインしていない）
