# music.youtube.com のタブを、ブラウザの拡張で家の端末の1つにする

状態: 採用（2026-10-24、本人の依頼。「拡張機能として、music.youtube.com にいるときに連携だけでも使える形」「Windows でも macOS でも Linux でも、Chrome と Firefox で使いたい」）

## 背景

ブラウザで wave を使いたい。前に検討した Web 版（家のサーバーがログインを持ち、音を中継する）は、ログインを家のサーバーに置くことと、音を家の回線で流すことが要るのでやめた。

music.youtube.com は、ブラウザでログインしたまま自分で音を鳴らせる。足りないのは端末の連携だけなので、拡張がタブと連携の間を橋渡しすれば、ログインも音も今のまま使える。

## 決定

1. **拡張（MV3）が、music.youtube.com のタブを家の端末の1つ（player、種類 `pc`）にする**（`browser-extension/`）
   - 1つの拡張を Chrome と Firefox（128 以上）で使う。`background` に `service_worker` と `scripts` の両方を書く
   - 連携の中身（暗号・鎖・doc・中継・加入・状態機械）は、Swift の `WaveCore/Connect` を TypeScript に移す。暗号は WebCrypto だけを使う（HKDF・HPKE は自分で組み、RFC のテストベクタと Kotlin・C# の見本で確かめる）
   - 身元の鍵は書き出せない CryptoKey のまま IndexedDB に置く
   - 端末名は「YouTube Music (Chrome)」などで、設定で変えられる。ほかの端末は `pc`・`phone`・`api` しか知らないので、新しい種類は作らない
2. **ページの読み書きは、YouTube Music の内部を MAIN world から使う**
   - 読む: `#movie_player` の API、`ytmusic-app` の redux の state、キューの係
   - 動かす: YouTube Music の画面が使う関数を呼ぶ（`handleCommand`・`onDrop` など）
   - ページの JS は信用しない。MAIN world から来た知らせは、隔離 world で形を確かめてから使い、拡張の権限には届かせない
   - YouTube Music の作りが変わると壊れる。壊れたら命令が失敗するか状態が空になるので、気づける
3. **加入はほかの PC と同じく、QR の文字と6桁**
   - ページがログインを知らせてから加わる。ログインしていれば、そのアカウントで照合する。ログインしていなければ、wave-api と同じ印（`wave-accountless-v1`、ADR-0015）で照合する
   - アカウントの値（`DATASYNC_ID`）は拡張の中でだけ使い、中継・ログに出さない（ADR-0002）。cookie は拡張から触らない
4. **タブが開いている間だけ中継につなぐ**
   - タブの content script が Port で背景を起こし続ける（MV3 の背景は 30 秒で止まるため）
   - タブが無くなれば中継から離れる。鳴らしていたタブが閉じたら、一時停止のカーソルを置く
5. **wave の決まりは拡張の側で守り、YouTube Music の同じ名前の機能は使わない**
   - シャッフル: YouTube Music のシャッフルはサーバーがキューを作り直し、足した曲が消える。そのため wave の決まり（QueueSession）どおりに拡張が並びを決めて送る
   - ほかの端末から移してきたキューは、自動再生（automix）を切って読み込む。「次に流れる曲」の消去も、自動再生を切る
   - 音量は PC の扱い（アプリの中の音量を家で合わせる）

## やめたこと

- **Web 版（家のサーバーがログインを持ち、音を中継する）**: ログインを家のサーバーに置き、音を家の回線で流すことになる
- **`watch_videos?video_ids=` の一時プレイリストでキューを読み込む**: www.youtube.com にしかなく、ページから CORS で読めない
- **新しい種類 `browser`**: 前の版の端末が捨てる

## 結果

- ログインも音もブラウザのまま、ほかの端末からタブを操作でき、タブへ再生を移したり、タブから移したりできる
- 配り方は本人が決める（Chrome はデベロッパー モードで読み込む、Firefox は署名が要る。SPEC の未決事項）
- 広告が入るアカウント（Premium でない、またはログインしていない）では、広告の間は曲として映らず、シークもできない。ヘッドレスの Chromium では、広告のまま進まず止まることがあった
