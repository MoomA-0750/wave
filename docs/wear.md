# 時計（Wear OS）版でできること・できないこと

スマホ版と同じことができるのを目指している（2026-10-19 時点）。

## スマホと同じようにできること

| スマホ | 時計 |
|---|---|
| ホーム（棚・絞り込みのチップ・最近再生した項目・新作） | 「ホーム」。チップは押すたびに次へ回す |
| 検索（候補・履歴・曲／アルバム／アーティスト） | 「検索」。語は声かキーボードで入れる。入力中の候補は出さない。探せるのは曲・アルバム・アーティストだけ（下の表） |
| ジャンル・気分 | 検索の「ジャンル・気分」 |
| ライブラリ（種類の絞り込み・並べ替え・検索・プレイリストの作成） | 「ライブラリ」。同じ |
| プレイリスト（再生・シャッフル・次に再生・キューに追加・絞り込み・並べ替え・曲を外す） | 同じ。曲を外すのは曲を長押しして開く曲の画面から |
| アーティスト（人気の曲・すべての曲・高く評価した曲・アルバム・新作・登録） | 同じ |
| アルバム（再生・シャッフル・まとめてキューへ） | 同じ |
| 曲の画面・曲のメニュー（次に再生・キューに追加・プレイリストに追加・ラジオ・アルバム・アーティスト） | 曲の画面。一覧の曲は長押しで開く |
| 再生画面（前・再生・次・評価／✓・キュー・歌詞） | 同じ。周りの輪が進み具合。ベゼルを回すと音量。イヤホンがつながっていればイヤホン、無ければ時計のスピーカーで鳴る。イヤホンは音量の画面から選べる |
| キュー（シャッフル・繰り返し・曲へ移る・外す・自分で足した曲を消す） | 同じ |
| 歌詞（時刻つきは今の行を追う・行を押すとそこへ） | 同じ |
| プレイリストに追加（✓の付いたものは外す・高く評価した曲・新しいプレイリスト） | 同じ |
| 再生履歴 | 同じ |
| Claude に聞く | 同じ。頼みは声かキーボード。スマホを通して中継へ届く |
| 端末（Connect v2 で Windows などの再生を操作・移す） | 「端末」。スマホの再生を操作し、時計とスマホの間で移す。スマホが映しているほかの端末も操作でき、スマホから家のほかの端末へ移せる |
| 設定（アカウント・再生履歴の送信・通知・ログアウト） | 同じ。ログアウトは時計だけ（スマホはそのまま） |

## 時計ではできない・しないこと

| スマホでできること | 時計で | 理由 |
|---|---|---|
| ログイン（WebView） | スマホから受け取る | 時計には WebView が無い。ADR-0011 |
| 曲の動画（MV）を重ねる | しない | 画面が小さく、電池を使う |
| キューの並べ替え（ドラッグ） | しない | 丸い小さな画面ではドラッグで並べ替えにくい。外す・移るはできる |
| 再生位置を指でずらす（シークバー） | 歌詞の行を押して移る | 丸い画面の輪は指でつかみにくい。ベゼルは音量に使う |
| 共有・リンクのコピー | しない | 時計には共有の仕組みが無い |
| アーティストのチャンネルの投稿（ライブの告知） | 出さない | 画像と長い文章が主で、時計では読みにくい |
| 中継（Connect v2）に時計そのものを加える | スマホを通す | 時計は tailnet に届かない |
| Claude の中継の設定（QR を読む） | スマホの設定を使う | 時計にカメラが無い。中継へはスマホを通す |
| 検索のライブ・ポッドキャスト・エピソード・歌詞の絞り込み | 出さない（曲・アルバム・アーティストだけ） | 時計の画面をまだ作っていない（スマホに足したとき、時計には作らなかった）。履歴に残ったポッドキャストを押すと、その語で探し直す |
| ポッドキャスト（登録・エピソードの一覧・ライブラリの絞り込み） | 出さない | 時計の画面をまだ作っていない（2026-10-13 にスマホだけに足した）。ライブラリの「ポッドキャスト」の絞り込みも外している |
| 新作の通知 | 出さない（一覧には入る） | スマホの通知が時計にも出るので、二重になる |
| 開発用の確認（設定の下の項目） | 出さない | adb の DebugReceiver からは使える |
